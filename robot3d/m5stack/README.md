# M5Stack StackChan structure files

From [m5stack/M5_Hardware](https://github.com/m5stack/M5_Hardware/tree/master/Products/K151_StackChan/Structures)
(MIT, see [LICENSE](LICENSE)), unchanged: the main body (the head behind the CoreS3), the base,
the servo body (the yaw part, with the turntable), its back cover and its top cover (inside the
head), and the base's bottom cover. robot3d places them by the
dimensions in M5Stack's drawing (https://docs.m5stack.com/en/StackChan, Model Size).
